Design Philosophy

Why Build NRKI v2 Around a Standalone CSS Library?

Modern personal websites swing between sterile corporate SaaS templates and heavy JS frameworks. Printed broadsheets solved high-density hierarchy centuries ago using deliberate typography, crisp 1px hairlines, 3px double rules, and disciplined ink contrast. Rather than hardcoding styles page-by-page, Issue 01 isolates and tests every token, element, and component inside one reusable stylesheet.

Architectural Guarantees
  • Zero !important: Ordered cleanly via @layer nrki.tokens, nrki.reset, nrki.elements, nrki.components, nrki.utilities, nrki.print;.
  • 5 Scoped Modes: Switch any individual specimen or section between light, dark, accent, faded, and uwu.
  • Zero Build Step: Works via plain <link rel="stylesheet"> in static HTML sites or React SPAs.

Library Extensions @layer API

Extending Without !important

Import nrki-broadsheet-library.css and declare your own custom layer after nrki.utilities, or redefine --nrki-* custom properties on :root or any nested [data-theme] container. 

@layer nrki.tokens, nrki.reset, nrki.elements,
       nrki.components, nrki.utilities, site.overrides;

@layer site.overrides {
  :root { --nrki-accent-primary: #1b4332; }
}
