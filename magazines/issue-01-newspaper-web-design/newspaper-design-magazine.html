Dispatch 01 / Philosophy

Broadsheet Hierarchy Without Bloat

Newspapers command attention through proportion, ink density, and disciplined border craft rather than JavaScript weight. By separating theme personality (data-theme) from color polarity (data-mode), one stylesheet transforms instantaneously from royal medieval parchment into serene Swiss minimalism or crisp botanical newsprint.

Use this magazine as a living storybook: flip pages cleanly in Broadsheet Spread mode on desktop, or glide through the Pocket Newspaper stream on mobile.

Dispatch 02 / 4 Themes

Typography & Border Grammars

Classic (Playfair Display + Newsreader + JetBrains Mono)
Crisp 1px column hairlines, 3px double masthead rules, and razor 0px corners.
Ancient (UnifrakturCook h1 + Cinzel + Cormorant Garamond + Courier Prime)
Old English blackletter titles, outward-curved medieval book corners, and SVG scrollwork dividers.
Minimalistic (Space Grotesk + Inter + Newsreader Quotes + IBM Plex Mono)
Barely any borders—tonal elevation, quiet hairline rules, and pure whitespace establish structure.
UwU (Fredoka + Nunito + Mali Quotes + DM Mono)
Pastel 2px dashed/solid frames, pill corners, offset candy shadows, and floral ornaments.

Library File GitHub (main)

Drop-In Standalone Stylesheet

Drop nrki-broadsheet-library.css into any external blog, documentation site, or SPA and toggle themes & light/dark modes with just two HTML attributes. 

<html data-theme="ancient" data-mode="light">
<link rel="stylesheet" href="nrki-broadsheet-library.css">

Extensibility @layer API

Extending Without !important

Add a custom override layer after nrki.utilities or introduce your own [data-theme="custom"] personality palette effortlessly. 

@layer nrki.tokens, nrki.reset, nrki.elements,
       nrki.components, nrki.utilities, site.overrides;

@layer site.overrides {
  [data-theme="custom"] { --nrki-accent-primary: #2d4f36; }
}
