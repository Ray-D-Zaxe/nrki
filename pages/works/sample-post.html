Building NRKI: Why Start with Plain HTML, CSS & JS

By NRKI · November 5, 2026 · 4 min read

This page serves as both a ready-to-copy post template for future blogs, essays, poems, and dev logs, and a living walkthrough of how NRKI comes together under the hood.

“Keep the foundation as simple and durable as newsprint; add interactivity only where it earns its place.”

1. How the Stylesheet Works

All visual styling lives in a single, layered CSS library: assets/styles/nrki-broadsheet-library.css. Theme personalities ([data-theme="classic" | "ancient" | "minimalistic" | "uwu"]) combine cleanly with ink polarity ([data-mode="light" | "dark"]). Because every component references semantic variables like var(--nrki-surface-paper) and var(--nrki-ink-primary), switching themes or toggling Paper/Night mode updates the entire site automatically.

2. How Interactive Filtering Works

In assets/scripts/main.js, the initializeFilterGroups() function looks for any section marked with data-filter-scope. Filter buttons specify data-filter-key and data-filter-value, while items specify matching data-* attributes: 

<!-- Example: Adding a filtered work row -->
<a class="nrki-work-row" href="./pages/works/my-poem.html"
   data-filter-item data-category="poem">
    <span class="nrki-work-category">Poem</span>
    <span class="nrki-work-main">
        <strong>Title of the Poem</strong>
        <span>A short one-line summary or opening verse.</span>
    </span>
    <time class="nrki-work-date">Nov 2026 →</time>
</a>

3. Adding React Islands or SPAs Later

When you are ready to drop a React component into a page (or build a standalone React mini-SPA under pages/projects/), you don’t need to rewrite the rest of the site. Simply add a mount container with data-react-island="my-widget":
