Building NRKI: Why Start with Plain HTML, CSS & JS

By NRKI · November 5, 2026 · 4 min read

This page serves as both a ready-to-copy post template for future blogs, essays, poems, and dev logs, and a living walkthrough of how NRKI comes together under the hood.

“Keep the foundation as simple and durable as newsprint; add interactivity only where it earns its place.”

1. How the Stylesheet Works

All visual styling lives in a single, well-commented file: assets/styles/style.css. At the top of that file, :root defines the light Herbarium Newsprint palette, while [data-theme="dark"] defines the reversed Pine Charcoal palette. Because every component references semantic variables like var(--bg-primary) and var(--ink-primary), toggling dark mode updates the entire site automatically.

2. How Interactive Filtering Works

In assets/scripts/main.js, the initFilterGroups() function looks for any section marked with data-filter-scope. Filter buttons specify data-filter-key and data-filter-value, while items specify matching data-* attributes: 

<!-- Example: Adding a new poem to index.html -->
<a class="work-row" href="./pages/works/my-poem.html"
   data-filter-item data-category="poem">
    <span class="work-category">Poem</span>
    <span class="work-main">
        <strong>Title of the Poem</strong>
        <span>A short one-line summary or opening verse.</span>
    </span>
    <time class="work-date">Nov 2026 →</time>
</a>

3. Adding React Islands or SPAs Later

When you are ready to drop a React component into a page (or build a standalone React mini-SPA under pages/projects/), you don’t need to rewrite the rest of the site. Simply add a mount container with data-react-island="my-widget":
