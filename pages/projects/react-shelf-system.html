Project 02 · Shipped Component System

Declarative React <Shelf /> & Gallery SPA

  • #react-18
  • #spa
  • #import-maps
  • #ui-components
GitHub Source ↗ Open Magazines Index ↗ View Media Shelf ↗

Originally designed for the Media Ledger page, <Shelf /> (assets/scripts/components/Shelf.js) was extracted into a reusable React 18 component that now powers all four collection pages across NRKI: Gallery, Projects, Works, and Media.

1. How <Shelf /> Works

The component accepts a declarative filters configuration array, an items dataset, and a custom renderCard function. It automatically extracts every unique #tag from the items to build an interactive tag filter bar alongside the primary category/status filters.

2. The Gallery SPA Overlay

On pages/gallery.html, assets/scripts/gallery-spa.js wraps the <Shelf /> component inside a stateful Single-Page Application. Each card renders its visual study, a brief summary, and an external link to the primary motif. Clicking the card opens an accessible modal overlay containing a short essay and a curated list of all inspirations and motifs, synchronized with the URL hash (e.g. #board-01).
