NRKI Broadsheet & Publishing Engine

  • #html5
  • #css-tokens
  • #es-modules
  • #print-css
GitHub Repository ↗ Live Front Page ↗ Printable CV Demo ↗

NRKI is a personal publishing system designed around a simple premise: a personal website should feel as durable, legible, and self-contained as a printed broadsheet newspaper, while remaining flexible enough to host interactive React micro-apps where needed.

1. Design Goals & Philosophy

  • Zero-bloat foundation: Semantic HTML5 landmarks, fluid CSS Grid typography, and native ES Modules that run directly in the browser without requiring a complex bundler just to edit text.
  • Multi-Theme Broadsheet Palette: Orthogonal CSS custom properties in assets/styles/nrki-broadsheet-library.css drive four personalities (Classic, Ancient, Minimalistic, UwU) across Paper (light) and Night (dark) ink modes.
  • Web + Print/PDF Resumes: Dedicated resume pages include a custom @media print stylesheet so clicking Print / Save as PDF outputs a crisp A4/Letter CV.
